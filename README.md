# UI-UX-Experiment2

## Aim:
To design a basic mobile and web layout using Figma by applying UI/UX design principles.
## Algorithm:

1. Open Figma and create a new design file. 
2. Create mobile and web frames with suitable dimensions.
3. Design a logo using suitable colours and fonts.
4. Add background images, text, buttons and icons.
5. Arrange UI elements using Gestalt principles.
6. Add navigation, product cards and interactive buttons.
7. Check the alignment, usability and save the final design.
